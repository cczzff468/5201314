## 提示词运行架构说明（摘要）

- **统一注册表**：所有 App 发给大模型的底层提示词以「条目（Entry）」形式登记在 `src/lib/prompt-entries.ts`（v63 全局预设管理器），每条可全局开关 / 编辑文本（`{{token}}` 模板）/ 调整注入深度；`buildPrompt(appId)` 按当前 App 拉取全部开启条目拼成完整 System Message。
- **注入深度（Depth）**：数值小 = 靠 Context 前部，大 = 靠近最新消息；同深度按 order 排序。
- **双端状态源**：客户端 kv 存储（键 `prompt-entries:state`）+ 服务端 `api/settings/prompt-state` 内存缓存同步。
- **零破坏原则**：无用户设置时，所有条目输出与原链路逐字节一致。
- **一轮微信单聊 system 由 20+ 模块块拼接**（人设七要素 + 沉浸规则 + 特殊消息标记 + 待处理清单 + 情绪/作息/时间感知 + 跨App近况 + 世界书 + 记忆 + 购物联动…），QQ 单聊 28 块拼装；各文档均附完整拼接结构图。
